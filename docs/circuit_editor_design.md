# Reading a molecular circuit

The first question in a pocket-conditioned model is where the pocket goes and where the molecule comes out. The next question is usually about one transformation, such as which representation reaches the decoder. These tasks need different amounts of detail. The guided editor gives the first question a short path and the second a view into the selected stage.

## What made the original canvas hard to read?

The previous default, **SE(3) De Novo**, has eight blocks, thirteen wires and forty-three stored block settings. Five wires leave the same pocket output. Only one goes to the encoder. The others supply docking, auditing, export and inspection. The decoder’s `molecules` output branches to ADMET and docking. These are useful dependencies, but presenting them all beside the encoder competes with the path a reader is trying to trace. The forty-three settings are a count of the graph data, independent of how many controls appear at once. [Original preset definitions](https://github.com/daniil-777/geneuclidean/blob/1fbdc35d403266abc4707c3a178ae6a361834ab1/web/src/lib/circuitCatalog.ts)

The guided editor opens the **Tourette & Schizophrenia Champion** preset. Its ten blocks and seventeen executable wires appear as four primary stages joined by three overview links. The decoder contains two parallel connections between the guidance block and the alignment block. Molecules and reward scores travel on distinct ports, so both remain visible in its detail view. [Champion preset](../web/src/lib/circuitCatalog.ts)

## Research and design choices

| Evidence | Application to this editor |
|---|---|
| In shortest-path experiments, Ware and colleagues found that direction changes along the path and edges crossing that path affected response time after path length was taken into account. [Original study](https://doi.org/10.1057/palgrave.ivs.9500013) | Keep the principal data flow in reading order. Show a selected block’s incoming and outgoing connections in separate rows with named endpoints. A user can trace an individual handoff without following a line through neighboring cards. |
| Ghoniem and colleagues compared graph representations across seven tasks. Following a path consistently favored a node-link diagram in their experiment. Looking up a link became easier with a matrix for larger, denser graphs. [Original study](https://mohammad.ghoniem.info/research/ivs-usability-2005.pdf) | Keep a visual path at the top. Use explicit endpoint pairs for local connection lookup. The study evaluated matrices, so the proposed row design still needs testing with this editor’s users. |
| Shneiderman distinguished gaining an overview, examining a selection and relating items. TensorBoard put similar ideas into practice by grouping related operations, separating high-degree noncritical nodes and exposing a selected operation’s inputs and outputs. [Task taxonomy](https://www.cs.umd.edu/users/ben/papers/Shneiderman1996eyes.pdf) · [TensorFlow design study](https://research.google/pubs/visualizing-dataflow-graphs-of-deep-learning-models-in-tensorflow/) · [TensorBoard interaction guide](https://www.tensorflow.org/tensorboard/graphs) | Open a stage in place with a clear route back to the overview. Group real circuit instances and expose their original ports. A collapsed stage can contain several operations. Opening it should require neither panning nor finding a socket at a small zoom level. |
| Node-RED lets authors expose a chosen set of properties on a subflow while its internal nodes remain editable. A disclosure button can support both pointer and keyboard operation with an explicit expanded state. [Node-RED subflows](https://nodered.org/docs/user-guide/editor/workspace/subflows) · [W3C disclosure pattern](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/) | Show settings only after a block is selected. Start with a small set relevant to its role, such as sample count on a decoder. Preserve access to the other parameters and their existing ranges in the full editor. |

We considered routing every wire around the existing nodes. ELK Layered supports layered diagrams with constrained ports and orthogonal routes. This is useful when editing individual wires, but every connection would still compete for space in the opening view. We also considered expanding every stage on the same canvas. For a circuit with feedback or several shared inputs, expanding one group would make the reader follow long connections across neighboring groups. A focused stage plus a full wiring view serves both reading tasks and preserves manual layouts. [ELK layout capabilities](https://eclipse.dev/elk/reference/algorithms/org-eclipse-elk-layered.html)

## Checks on graph meaning and usability

| Task | How to check it |
|---|---|
| Trace the default generation path | Identify the pocket, encoder, decoder and candidate SMILES without zooming. SMILES represents the decoder’s molecular output. Check the source port in the graph and the generated Python. Run the browser preview and verify that its curated example strings are labeled with their provenance. The browser selects these examples from the molecule index. [Code generator](../web/src/lib/circuitEngine.ts) |
| Inspect a fork or loop | In SE(3) De Novo, locate both consumers of the decoder’s molecule output. Load the active-learning preset and trace the feedback edge. Its direction and endpoint ports must survive grouping. NanoFold and blank circuits should show only the stages their data supports. [Preset catalog](../web/src/lib/circuitCatalog.ts) |
| Edit without changing the circuit by accident | Open a stage, change one block setting, return, and inspect the same block in the full editor. Compare the exported nodes, edge endpoints and other settings before and after. |
| Read the layout across devices | At phone, tablet and desktop widths, inspect the generation path and the busiest stage. Check the bounds of adjacent cards, connector lanes and controls. Use the keyboard to open a stage, select a block and return to the stage selector. |

Geometry and round-trip tests can establish that controls fit and graph meaning survives. To assess whether people understand the design faster, give first-time users the tracing and editing tasks above, rotate the order of the two interfaces, and measure completion time, wrong destinations and successful edits. An automated browser run cannot supply those human measures.
